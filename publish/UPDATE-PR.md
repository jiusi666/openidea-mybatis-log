### jiusi.mybatis-log → 0.2.1

Adds `0.2.1` to the version list; the earlier `[[versions]]` tables stay published for anyone on an older `engines.openidea`. Release:
https://github.com/jiusi666/openidea-mybatis-log/releases/tag/v0.2.1

#### What changed

- 0.2.1: pasting now saves a history entry after a short pause, consecutive edits merge into one entry, labels show `SQL type / count / SQL prefix`, and legacy stored history still loads.
- 0.2.0: SQL type badges, logger grouping, elapsed time and Total/Updates rows, a parameter comparison table, filtering by type/keyword, static risk hints, comment highlighting, plus Hibernate / P6Spy / log4j2 JSON log dialects.
- Capabilities are unchanged: only `editor.read` + `storage` (both Low).

The entry also declares `suggest` (project-relative paths, no globs). This is listing metadata only, not a new capability.

#### Package

`jiusi.mybatis-log-0.2.1.oiplugin`, built from the source in this repository for plugin API `^1.4`, signed by publisher `jiusi`. Capabilities are unchanged. No new `net:`, `process:` or other high-risk capability is requested.
